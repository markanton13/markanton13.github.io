Enterprise Assessment & Analytics System

Completed

Secure frontend taker UI with a memory-locked timer, paired with a rich analytics dashboard for admins.

A fully custom, scalable, and secure Assessment System built entirely on the Google Workspace ecosystem. It eliminates the need for expensive third-party testing software by turning Google Sheets into a powerful, real-time relational NoSQL database.

The system features a cheat-resistant frontend for test-takers and a robust Admin Dashboard that automatically calculates pass rates, identifies common distractors (wrong answers), and tracks user conversion across multiple attempts.

  • Memory-Locked Timer: Server-synced countdown that prevents cheating via tab closures or page refreshes.
  • Smart Pagination: Questions are served one at a time with a master accordion review screen to reduce cognitive overload.
  • Omni-Scanner Auth: Dynamic role-based access control granting Admin, Creator, or Collaborator permissions.
  • Item Analysis Engine: Automatically calculates Pass/Fail rates for every individual question.
  • Auto-Importer: Instantly converts existing Google Forms and historical responses into the platform with zero data duplication.

Tech Stack: Google Apps Script • JavaScript (ES6) • HTML5/CSS3 • Google Sheets API

Impact: Replaced manual testing and grading with a fully automated, scalable enterprise platform.
